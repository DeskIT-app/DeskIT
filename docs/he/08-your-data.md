# 8. הנתונים שלך

**בשני משפטים.** כל מה שדסק-איט שומר עליך נמצא בתיקייה אחת, `%LOCALAPPDATA%\DeskIT`,
והדברים היחידים מחוצה לה הם מפתחות הענן שלך במנהל האישורים של חלונות, ואם בחרת בזה — רשומת
ההפעלה עם חלונות. מוחקים את התיקייה ודסק-איט שכח אותך.

## התיקייה

מדביקים `%LOCALAPPDATA%\DeskIT` בשורת הכתובת של סייר הקבצים. **Settings > The app** פותח
כל אחד מאלה בכפתור:

| מה | איפה | הערות |
|---|---|---|
| מה ששינית | `settings.toml` | רק ההגדרות ששונות מברירות המחדל; ברירות המחדל וההסבר לכל מפתח ב־`defaults.toml` שליד התוכנה |
| עובדות על המחשב הזה | `state.json` | המיקרופון, מיקום הנקודה, השכבה, אם האשף רץ |
| ההסכמות שלך | `consent.json` | שורה לכל שער ענן שפתחת, עם גרסת התנאים שראית |
| מילים שלמד | `vocab.json` | הזוגות שלימדת אותו |
| הצעות הקריאה השנייה | `review.json` | |
| הדיווחים שלך | `problems.json`, `problems\` | במחשב הזה אלא אם שלחת אחד |
| כל מה שאמרת | `logs\transcripts.log` | כל הכתבה, תרגום וחיפוש, למספר הימים שקבעת |
| היומן של האפליקציה | `logs\app.log` | בלי תמלולים — מה שבקשת תמיכה עשויה לכלול |
| כל חיבור | `logs\network.log` | מקום Network קורא את זה |
| ההקלטות האחרונות | `audio\recent`, `audio\pending` | recent: ה־N האחרונות ללמידה; pending: הכתבה שמחכה למודל |
| המודל העברי | `models\` | 1.62 ג׳יגה; מוחקים ו־Home מציע את ההורדה שוב |
| הספריות של אנבידיה | `packs\` | חבילת הכרטיס, אם התקנת |
| צילומי מסך וקליפים | `captures\` | |
| האסימון של הטלפון | `secrets\` | מוצפן ב־DPAPI של חלונות עצמו לחשבון שלך |

## כמה זמן דברים נשמרים

> Audio: the last 50 recordings · History: 30 days · Learned words: until you forget one · Reports: on this PC until you delete them · Lookups: the last 500 answers, on this PC · The speech model: until you delete it · Nothing on any server unless you pressed Send.

כלומר: שמע — 50 ההקלטות האחרונות; היסטוריה — 30 יום; מילים שלמד — עד שתשכח אחת; דיווחים —
במחשב הזה עד שתמחק; חיפושים — 500 התשובות האחרונות, במחשב הזה; מודל הדיבור — עד שתמחק; שום
דבר בשום שרת אלא אם לחצת Send. המספרים הם הגדרות: `vocab.keep_audio`, `history.keep_days`,
`lookup.cache_entries` בדף ההגדרות, ו־`history.keep_days = 0` מכבה את ההיסטוריה.

## מחיקה

- **דבר אחד:** פותחים את התיקייה מ־**Settings > The app** ומוחקים את הקובץ — דסק-איט יוצר
  חדש וריק. המודל: מוחקים את `models\` כשדסק-איט סגור, או **Delete the model** ב־
  **Settings > The app**.
- **הכול:** סוגרים את דסק-איט ומריצים, מתיקיית ההתקנה (`%LOCALAPPDATA%\Programs\DeskIT`):

  ```
  python\python.exe app\main.py --reset-data --yes
  ```

  זה מסיר את המילים שלמד, ההיסטוריה, ההקלטות, ההצעות, הדיווחים, המטמונים והיומנים ושומר את
  `settings.toml`, `state.json` והמפתחות שלך.
- **הסרה** שואלת "Remove my data too?" — כן מריץ את אותו איפוס ומסיר את רשומת ההפעלה עם
  חלונות; ברירת המחדל לשמור.
- **מפתחות:** **Settings > Privacy > YOUR CLOUD KEYS > Remove**, או מוחקים `DeskIT/groq`
  ו־`DeskIT/gemini` בעצמכם בלוח הבקרה > מנהל האישורים.
- **שורות ה־hook של Claude Code:** המתג תחת **Settings > The app** מסיר את שתי השורות מ־
  `~/.claude/settings.json`.

## מעבר למחשב אחר

מעתיקים את התיקייה (`%LOCALAPPDATA%\DeskIT`) לאותו מקום במחשב השני אחרי שמתקינים שם את
דסק-איט. מפתחות אף פעם לא בתיקייה: מדביקים אותם שוב. `state.json` נוקב במיקרופון ובשכבה
של המחשב הזה; מוחקים אותו במחשב השני והאשף רץ פעם נוספת.
