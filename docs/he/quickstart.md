# התחלה מהירה

1. **להשיג.** `winget install YoavShimron.DeskIT`, או להוריד את `DeskIT-Setup-x.y.z.exe`
   מ[הגרסה האחרונה](https://github.com/DeskIT-app/DeskIT/releases/latest). אם חלונות אומר
   "Windows protected your PC": **More info** ואז **Run anyway** ([למה](01-install)).
2. **להתקין.** בלי סיסמת מנהל. דסק-איט נפתח לבד בסוף.
3. **האשף.** שבעה דפים; רק שלושה שואלים משהו. מדברים למיקרופון, לוחצים **Download**
   למודל העברי (1.62 ג׳יגה, פעם אחת), וכל השאר **Next**.
4. **הסיור.** ארבעה כרטיסים ליד הנקודה מראים את הנקודה, את המקש ואת המדף. **דלג** אם
   ממהרים; **Show the tour** בהגדרות מחזיר אותו.
5. **להכתיב.** לוחצים בשדה טקסט כלשהו, מחזיקים את המקש, מדברים, משחררים. הטקסט העברי
   מודבק במקום הסמן.

שום דבר לא יוצא מהמחשב עד שתפעיל את זה בעצמך — מקום **Network** בלוח המחוונים מראה כל
בקשה, ו[פרק 4](04-privacy) מראה איך לבדוק בעצמך.
