# 3. הכתבה

**בשני משפטים.** לוחצים במקום שרוצים את הטקסט, מחזיקים **Right Ctrl**, מדברים, משחררים —
העברית מופיעה אצל הסמן. כל השאר בפרק הזה הוא עידון של התנועה האחת הזאת.

## להחזיק, לנעול, אנגלית

- **להחזיק ולדבר.** מחזיקים **Right Ctrl**, מדברים, עוזבים. כל עוד המקש לחוץ כרטיס קטן
  (הרמז) אומר מה שאר המקשים עושים ברגע הזה.
- **לנעול.** תוך כדי החזקה של Right Ctrl, לוחצים **←** (חץ שמאלה): ההקלטה ננעלת, עוזבים את
  Ctrl ומדברים כמה שרוצים. לוחצים ← שוב כדי לתמלל, **Esc** כדי לבטל.
- **אנגלית.** דסק-איט מזהה משפט שנאמר באנגלית כשמזהה האנגלית מותקן ([פרק 2](02-first-run),
  רק בכרטיסי אנבידיה) ומתמלל אותו כאנגלית. יש גם מקש נפרד "Dictate English" שאפשר להגדיר
  במקום **Keys**.

![כרטיס הרמז, כשהמקש מוחזק](../img/03-hint.png)

## הנקודה

נקודה קטנה יושבת בפינה של המסך הראשי (**Settings > General** בוחר פינה). הצבע שלה
הוא המצב:

| צבע | משמעות |
|---|---|
| כחול קריר | מקשיב — אפשר להחזיק את המקש מתי שרוצים |
| אדום | מקליט עכשיו |
| אדום, נושם | נעול: מקליט בלי שהמקש מוחזק |
| ענבר | מתמלל, או עסוק במעבר ענן |
| אפור, בלי זוהר | מושהה (מקש ההשהיה, או משחק במסך מלא) |

![צבעי הנקודה](../img/03-dot-states.png)

לוחצים על הנקודה ופאנל (המדף) נפתח לידה: מה האפליקציה עושה, מה מחכה לך, והדברים האחרונים
שאמרת.

![המדף](../img/03-shelf.png)

**Move**, בראש הפאנל, שם את הנקודה איפה שרוצים: הפאנל נסגר, אור חם נדלק סביב כל מסך,
ולוחצים על הנקודה, מחזיקים וגוררים אותה לאן שרוצים — לכל מסך, כמה פעמים שרוצים. **Done**
(הכרטיס הקטן בראש המסך) או **Enter** משאירים אותה שם; **Esc** מחזיר אותה. אותו דבר נמצא גם
ב-**Settings > General** בתור **Move the dot**.

![הזזת הנקודה](../img/03-move.png)

## לאן הטקסט הולך

התמלול מונח על הלוח של חלונות ומודבק עם Ctrl+V לחלון שמתחת לסמן; הלוח משוחזר אחר כך. שתי
תוצאות שכדאי לדעת:

- **היסטוריית הלוח של חלונות** (Win+V) עשויה לשמור תמלולים קודמים אם הדלקת את התכונה הזאת
  בחלונות, וסנכרון הלוח לענן של חלונות ישלח אותם למיקרוסופט. זה מעשה של חלונות, לא של
  דסק-איט; דסק-איט שומר היסטוריה משלו למספר הימים שקבעת ([פרק 8](08-your-data)).
- **חלון שרץ כמנהל** (חלון מורם) מסרב להדבקה מתוכנה רגילה — כלל של חלונות, לא של דסק-איט.
  הטקסט על הלוח שלך: לוחצים Ctrl+V שם בעצמכם. דסק-איט אף פעם לא רץ כמנהל.

## לתקן מילה

לוחצים **Ctrl+F9** מיד אחרי הכתבה עם מילה שנשמעה לא נכון: כרטיס מציג את המשפט, בוחרים את
המילה השגויה ומקלידים את הנכונה. דסק-איט לומד את הזוג ומחיל אותו על הכתבות הבאות; מקום
**Corrections** מציג כל זוג שהוא מכיר ומאפשר לשכוח אחד.

דסק-איט גם קורא כל הכתבה פעם שנייה בעצמו (הקריאה השנייה) ומציע תיקון כששתי הקריאות
חלוקות; ההצעה היא כרטיס עם **Yes** ו־**No**. במחשב בלי כרטיס אנבידיה הקריאה השנייה כבויה.

![מקום Corrections](../img/03-corrections.png)

## שאר המקשים

| מקש | עושה |
|---|---|
| Ctrl+F2 | לפסק את מה שהרגע הודבק |
| F8 | לתרגם את הבחירה |
| Ctrl+F8 | לחפש את המילה המסומנת |
| Ctrl+F10 | לשאול על המסך ([פרק 7](07-screen)) |
| Win+Shift+S | צילום מסך ([פרק 7](07-screen)) |
| Ctrl+F12 | להקליט את המסך |
| Insert | השהיה / המשך |
| Ctrl+Alt+R | לדווח על בעיה ([פרק 9](09-reporting)) |

כולם במקום **Keys** בלוח המחוונים, דולקים על מקלדת מצוירת, ואפשר לשנות אותם שם.
